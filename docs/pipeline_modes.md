# 矿物处理流水线模式指南

本项目提供两种可自由切换的矿石加工流水线模式，通过配置文件 `config/tfc_oreprocess-common.toml` 中的 `pipelineMode` 项进行控制：

```toml
[general]
# 矿物加工流水线模式: STANDARD (精简标准模式) 或 TEMPLATE_CLASSIC (模板模组经典多级扩展流水线)
pipelineMode = "STANDARD"
```

## 1. STANDARD（默认精简标准模式）

适合追求轻量化、直观快捷体验的整合包。

- **加工链路**：
  `TFC 原矿（锤子敲碎 或 Create 机械压板单次冲压） -> 碎矿 -> TFC 原生 Sluice 洗矿 -> 5 mB 矿粉 -> 25/100 mB 矿团 -> TFC 熔炼`
- **品位规格产出**：
  原矿手工锤碎与 Create 机械压板冲压均严格遵循 TFC 原矿品位细分：
  - `small`（小矿粒）：产出 1 份碎矿
  - `poor`（贫矿）：产出 3 份碎矿
  - `normal`（正常矿）：产出 5 份碎矿
  - `rich`（富矿）：产出 7 份碎矿
- **洗矿与熔炼**：
  碎矿投入原生 Sluice 洗矿，产出 5 mB 矿粉（默认 1.5x 倍率）与副产物，可逆合成为 25/100 mB 矿团进行熔炼。
- **机械联动**：
  - **Create 机械动力**：原矿在机械压板（Mechanical Press）下单次冲压即可直接破碎为对应品位数量的碎矿，无需多重序列组装。
  - **沉浸工业**：提供 Crusher 的品位分级粉碎配方。

## 2. TEMPLATE_CLASSIC（模板模组经典多级扩展流水线）

适合追求硬核深度、多级细化品位产出以及全科技模组联动的整合包。

- **4 档品位细分产出**：
  - `small`（小矿粒）：产出 1 份碎矿
  - `poor`（贫矿）：产出 3 份碎矿
  - `normal`（正常矿）：产出 5 份碎矿
  - `rich`（富矿）：产出 7 份碎矿
- **多途径机械粉碎**：
  - **TFC 手推磨（Quern）**：将各品位原矿研磨为对应数量的碎矿。
  - **Create 机械动力**：
    - 石磨（Milling）：原矿粉碎为碎矿 + 50% 概率额外产出矿粉副产物。
    - 粉碎轮（Crushing）：原矿粉碎为碎矿 + 50% 概率 2 份矿粉副产物。
  - **Immersive Engineering 沉浸工业**：
    - Crusher 粉碎机：按 4 档品位产出碎矿，并附带 20% 矿粉副产物。

两种模式的配方均由 NeoForge 条件加载器（`tfc_oreprocess:pipeline_mode`）严格隔离，切换模式仅需修改配置文件或游戏内重载，互不冲突。
